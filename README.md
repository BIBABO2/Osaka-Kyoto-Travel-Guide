## 三、各文档内容概要

**公共交通乘车攻略 v1**（`Osaka-Kyoto-Transit-Guide-v1.*`）

1. 三条铁律 → 2. 公司标识与车站导视图解（JR／关西私铁／地下铁与巴士各一张速查图）→ 3. 改札机（闸机）完全解读 → 4. 坐电车四条路径（IC 卡／纸票／手机 IC／QR）→ 5. 列车种类详解（各停→新快速→特急→新干线、特大行李规则）→ 6. 关西主要线路怎么买票怎么坐 → 7. 京都/大阪巴士规则 → 8. 三种换乘与直通运转 → 9. IC 卡（ICOCA/Suica/手机 IC、退卡、优惠券取舍）→ 10. 对号入座与座位规则 → 11. 现场应急处理 → 12. 避坑清单 → 13. 行前工具与话术 → 14. 中日英对照表 → 15. 来源清单、核验矩阵、图片版权、更新记录。

阅读辅助：正文的「第 9 章」「见 8.3」等序号可直接点击跳转；桌面与手机端右下角都有悬浮「回到目录」按钮；相邻照片采用两图并列排版，减少翻页长度。

**乘车速查卡 v1**（`Osaka-Kyoto-Transit-Cheatsheet-v1.*`）：三条铁律、闸机四步、京都/大阪巴士口诀、IC 卡要点、必背 10 个日语词、三个最容易走错的换乘站。

**大阪・京都 国庆旅游攻略 v1**（`Osaka-Kyoto-NationalDay-Travel-Guide-v1.*`）：出发前准备、深圳→香港机场衔接、入境与海关、抵达后交通、旅游阶段衣食住行与购物免税、风俗礼仪、离境与复查清单，每条事实附来源编号。

**攻略制作指南 v1**（`Osaka-Kyoto-Guide-Making-Playbook-v1.*`）：信息来源分级、三重核验规则、标记体系、检索方法与更新流程。

## 四、版本与命名规则

- 网页与 Markdown **共用同一基名**：`…-v1.html` 与 `…-v1.md` 成对出现。
- 内容有实质变化时升版本号（v1 → v2），**旧版本文件保留不删除**，并在各文档「更新记录」登记。
- 旧地址不作保留（已按用户要求移除），分享请使用本页或上表直链。

按来源整理的关键事实均标注了抓取日期（2026-09-11）；票价、时刻、规则类信息出行前请再核对官方页面。文档中的公司标识与实拍照片来自 Wikimedia Commons，版权归各公司所有，仅用于乘车识读说明。

## 五、本地维护（可选）

文档在本机 `G:\ChatGPT\Projects` 编辑，脚本位于 `tools\`：

```powershell
pwsh -File tools\publish.ps1 -Message "更新说明"
```

该命令会：用 `tools/build-site.js` 重建网页 → 校验目录锚点/图片/表格 → 同步全部文档与图片到仓库 → 提交并推送到 GitHub。
